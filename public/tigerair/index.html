Tigerair Card Upgrade
A Boarding-Themed Digital Experience

UI/UX Design Front-end Development Visual Identity

I worked across the card visuals and campaign page, turning credit card benefits into a travel-themed digital experience. I also built the page interactions and animations using HTML, CSS, and JavaScript.

  • My Role: Visual Designer, UI/UX Designer, and Front-end Developer.
  • Goal: Refresh the Tigerair card experience to attract more customers, strengthen its market position, and make card benefits easier to explore through clear layouts and engaging interactions.
🚀 See It in Action
01. Key Highlights

90-Day End-to-End Ownership

Delivered the full lifecycle from physical card design to frontend launch within a 90-day sprint, ensuring 100% fidelity by eliminating cross-department handoff gaps

Clearer Benefit Navigation

Gave the main 3% reward visual priority and used a Swiper.js carousel to present the remaining four benefits in a compact, mobile-friendly layout.

Lightweight Motion Design

Used CSS and JavaScript animations instead of video assets for selected interactions, keeping the boarding-themed introduction closely integrated with the webpage.

02. Challenges & Solutions

Strategic Layouts

Making Five Card Benefits Easier to Browse on Mobile

Problem:
Tigerair wanted to showcase all five major card benefits. On mobile screens, displaying every benefit in a standard vertical layout would make the page much longer.

Solution:
Visual Hierarchy & Interactive Carousel
I gave the main 3% reward the strongest visual emphasis and used a Swiper.js carousel for the remaining four benefits. This helped users focus on the key offer while browsing the other benefits in a more compact layout.

Organizing Dense Information Without Overwhelming Users

Problem:
The page contained detailed offer terms and strong brand colors, which could make the content feel dense and compete for attention.

Solution:
1.Color Sections
I used warm orange, red, and yellow tones to separate content sections and guide users through the page. I also designed two modal styles:

2.Two-Tiered Modals

  • Highlight Modal:Inspired by airport flight information displays (FIDS), presenting the five key benefits at a glance.
  • Standard Modal:A clean, white layout for detailed terms and conditions.
03. Design Concept

A Boarding-Themed User Journey

I created an animated introduction inspired by the airport boarding experience to connect the campaign with Tigerair's brand identity.

  • Boarding Intro:An animated opening introduces the new card upgrade.
  • Gate Agent Mascot: The Tigerair mascot appears as a gate agent to introduce the new card.
  • Visual Focus: An airport display board (FIDS) pops up to show the new card design before the animation fades out into the main content.
04. Technical Implementation

Perfecting UX with Code

Layout Shift Prevention (Anti-Jitter)

I used a MutationObserver to monitor modal visibility and dynamically compensate for scrollbar width. This prevents the page content from shifting horizontally when the background scroll is locked.

// Monitor popup state and fix the layout shift
const observer = new MutationObserver((mutations) => {
let scrollBarWidth = window.innerWidth - document.documentElement.clientWidth;

if ($popup.is(':visible') && scrollBarWidth > 0) {
$('body').css({
'overflow': 'hidden',
'border-right': scrollBarWidth + 'px solid transparent',
'box-sizing': 'border-box'
});
} else {
$('body').css({ 'overflow': '', 'border-right': '' });
}
});

Lightweight CSS Animations

I used CSS keyframes for the card's rocking motion and the CTA's breathing effect, reducing reliance on video assets for these interactions.

// A breathing animation for the CTA button
@keyframes rockCCW {
0%, 100% { transform: rotate(0deg); }
50% { transform: rotate(-1deg); }
}


// A physics-based shaking effect for the new tiger card
.hand-item-card-anim {
animation: rockCCW 0.7s ease-in-out infinite;
transform-origin: bottom center;
}


// A physics-based shaking effect for the designated channels
.hand-item-light-anim {
animation: sequence-breath 4.5s ease-in-out infinite;
transform-origin: center center;
}

Sequenced Intro Animation

I used JavaScript timing controls to coordinate the boarding gate, mascot, display board, and card reveal, creating a consistent transition into the main content.

// Animation Orchestrator: Sequence Controller
const animationTimeline = [
{ el: boardingGate, class: 'visible', delay: 0 },
{ el: newUpgrade, class: 'breathe', delay: 250 },
{ el: noticeBoard, class: 'slide-down', delay: 350 },
{ el: tigercard, class: 'fade-in', delay: 450 }
];

// Execute sequence with cumulative delays
let currentTime = 0;
animationTimeline.forEach(step => {
currentTime += step.delay;
